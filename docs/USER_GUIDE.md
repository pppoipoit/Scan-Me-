# 📖 คู่มือการใช้งาน (User Guide) - Scan Me!

คู่มือนี้จะแนะนำขั้นตอนการใช้งานโปรแกรม **Scan Me!** ตั้งแต่การเริ่มต้นเปิดใช้งาน จนถึงการนำข้อมูลไปประยุกต์ใช้

---

## 1. การเริ่มต้นเปิดโปรแกรม

### วิธีที่ง่ายที่สุด:
1. ไปที่โฟลเดอร์ `D:\Project\Scan Me!`
2. ดับเบิลคลิกไฟล์ **`run.bat`**
3. หน้าต่างโปรแกรม GUI สี Dark Modern จะปรากฏขึ้นมาพร้อมใช้งาน

## 3. ขั้นตอนการสแกนโฟลเดอร์

### ขั้นตอนที่ 1: เลือกโฟลเดอร์เป้าหมาย
- คลิกปุ่ม **📁 Browse...** เพื่อเลือกโฟลเดอร์ในเครื่องที่ต้องการสแกน หรือพิมพ์ Path ลงในช่อง Target Folder โดยตรง

### ขั้นตอนที่ 2: เลือกประเภทไฟล์และตัวเลือกเสริม
- **Filter Preset**: เลือกหมวดหมู่ไฟล์ที่ต้องการสแกน เช่น:
  - `🌐 All Files (*.*)`: สแกนไฟล์ทุกชนิด (ค่าเริ่มต้น)
  - `📦 Installers & Packages`: สแกนเฉพาะ `.exe`, `.msi`, `.zip`, `.msix`, `.rar`, `.7z`
  - `💻 Code & Dev`: สแกนเฉพาะไฟล์โค้ด `.js`, `.py`, `.ps1`, `.json`, `.html` ฯลฯ
  - `📄 Documents`: สแกนเฉพาะไฟล์เอกสาร `.pdf`, `.docx`, `.xlsx` ฯลฯ
  - `🎨 Media`: สแกนเฉพาะไฟล์ภาพและเสียง `.png`, `.jpg`, `.mp4` ฯลฯ
  - `⚙️ Custom Extensions`: กำหนดนามสกุลไฟล์เองตามต้องการ
- **ตัวเลือกเสริม (Options)**:
  - ☑️ **Check Duplicates (MD5 Hash)**: ติ๊กถูกหากต้องการตรวจสอบไฟล์ที่มีข้อมูลซ้ำกัน
  - ☑️ **Extract EXE/App Version & Metadata**: ติ๊กถูกหากต้องการอ่านเวอร์ชันและชื่อผู้พัฒนาของไฟล์โปรแกรม
  - ☑️ **Include Hidden Files**: ติ๊กถูกหากต้องการรวมไฟล์และโฟลเดอร์ที่ซ่อนอยู่

### ขั้นตอนที่ 3: กดปุ่มเริ่มสแกน
- คลิกปุ่ม **🚀 START SCAN** สีเขียวสดใสด้านล่างขวา
- แถบ Progress Bar จะแสดงความคืบหน้า และตารางข้อมูลจะแสดงผลการสแกนแบบสดทันทีที่เสร็จสิ้น

---

## 4. การค้นหาและส่งออกผลลัพธ์

1. **ค้นหาแบบรวดเร็ว (Quick Filter)**: พิมพ์คำค้นหาในช่อง `🔍 Quick Filter` ด้านบนตาราง ข้อมูลในตารางจะถูกกรองตามชื่อไฟล์ นามสกุล หมวดหมู่ หรือ Path แบบทันที
2. **ส่งออกเป็น JSON (Export JSON)**: คลิกปุ่ม **💾 Export JSON** เพื่อบันทึกผลลัพธ์โครงสร้าง JSON สำหรับนำไปใช้งานร่วมกับแอปพลิเคชันหรือ AI อื่นๆ
3. **ส่งออกเป็น CSV (Export CSV)**: คลิกปุ่ม **📊 Export CSV** เพื่อนำข้อมูลไปเปิดและวิเคราะห์ต่อใน Microsoft Excel หรือ Google Sheets
4. **เปิดโฟลเดอร์ผลลัพธ์ (Open Output)**: คลิกปุ่ม **📂 Open Output** เพื่อเปิดดูไฟล์ผลลัพธ์ที่บันทึกไว้ในระบบ
